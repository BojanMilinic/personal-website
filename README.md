# Personal Website - Bojan Milinic

Built with [Astro](https://astro.build) + [Tailwind CSS](https://tailwindcss.com). Hosted on Netlify.

---

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

Open hosted site: https://bojanmilinic.netlify.app/

---

## Reading Wall

The interactive Reading Wall lives at `/reading`. Its catalog is maintained in
`src/data/books.js`; each book's ISBN is used to request its cover from Open
Library at runtime. The page samples each loaded cover to color the book tile,
with a built-in fallback color when a cover is unavailable.

---

## Writing

The live Writing section is generated by Astro from Markdown files in `src/content/posts/`.

Add a post as `src/content/posts/my-post.md`, run `npm run build`, and Astro generates `/posts/my-post/`. Lab notes work the same way from `src/content/lab/` and generate `/lab/...` routes.

Pelican is not part of the normal live-site publishing workflow. It is only preserved as an archived blog experiment under `/blog-archive/02-pelican/index.html`.
